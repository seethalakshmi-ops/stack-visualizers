Stack follows LIFO

LIFO means Last In, First Out. The last website you visit is the first one removed when you go back.

C concept
/* Stack using Array */
int stack[MAX];
int top = -1;

/* PUSH */
top++;
stack[top] = item;

/* POP */
item = stack[top];
top--;
